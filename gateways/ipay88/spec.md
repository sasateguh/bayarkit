### Delivery

### Signature (current: HMAC-SHA512) — confirmed on official host

| Item                          | Value                                                                                                                       | Source                                                                                                            |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Algorithm                     | HMAC-SHA512                                                                                                                 | T-HMAC line 45–46; JS lines 8–11 (`CryptoJS.HmacSHA512(msg, key)`)                                                |
| Key                           | MerchantKey (UTF-8 bytes)                                                                                                   | T-HMAC line 46 `GetHmacSHA512(strBeforehash, MerchantKey)`                                                        |

## 8. Contradictions (most valuable)

| #   | Contradiction                                                                                                                                                                                                                                                                         | Sources                                      |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| C1  | **Xfield1 in request signature.** SPEC 1.6.4.4 §3.1 says message = key+code+refno+amount+currency+**Xfield1**; the official tool builds key+code+refno+amount+currency only. Identical when Xfield1 is empty; differs as soon as Xfield1 is used.                                     | SPEC p.23 vs T-HMAC line 35                  |
| C2  | **Amount stripping.** SPEC: "Remove the "." and "," in the string". Official tool uses JS `.replace(".", "").replace(",","")` → only the first occurrence of each, so `1,000,000.00` → `1000,00000` in the tool vs `100000000` by a full strip. Which the server uses is UNCONFIRMED. | SPEC p.23 vs T-HMAC line 31                  |
| C3  | **Algorithm generation.** SPEC 1.6.4.4 field table says SignatureType = `HMACSHA512` only; official host still serves SHA-1 and SHA-256 tools and the HMAC tool still offers SHA1/SHA256. Whether production still accepts SHA256 is UNCONFIRMED.                                     | SPEC p.9 vs T-256, T-SHA1, T-HMAC `<select>` |
| C4  | **Response signature for the SOAP re-query.** WSDL response has `Signature`; SPEC's response table for it lists none and gives no formula.                                                                                                                                            | WSDL vs SPEC p.20                            |
| C5  | **Paid time type.** SPEC table "Datetime 20"; SPEC sample `2020-02-25` (date only); WSDL `s:string`.                                                                                                                                                                                  | SPEC p.20–21, WSDL                           |
| C6  | **Re-query field name.** enquiry.asp uses `RefNo`; SOAP uses `ReferenceNo` (≤50) for the same value.                                                                                                                                                                                  | SPEC p.18–19, WSDL                           |
| C7  | **Other iPay88 countries differ — do not copy.** iPay88 Indonesia (official, separate entity) signs `                                                                                                                                                                                 |                                              | MerchantKey |     | MerchantCode |     | RefNo |     | Amount |     | Currency |     | ` with plain SHA-256 and IDR without decimals. | https://www.ipay88.co.id/docs/core-api (section "Request Signature") (Indonesia only) |
