## Airwallex traps (each from an official source or a sandbox measurement)

- Amounts are decimal MAJOR units (MYR 12.50 is sent as 12.50), yet every official PaymentIntent example sends "amount": 100, so a cents habit overcharges 100x. *(https://www.airwallex.com/docs/developer-tools/ai-agent-payments-integration.md lines 40-43; using-payments-intent-api.md line 15 vs quickstart.md line 70)*
- Webhook x-signature is lowercase hex HMAC-SHA256 over x-timestamp (milliseconds, as received) concatenated with the RAW body; the official Koa sample nonetheless falls back to JSON.stringify(parsed body), which breaks verification, and test events are signed with the secret in their client-secret-key header instead of the subscription secret. *(listen-for-webhook-events.md lines 35-36, 83, 86-98, 178)*
- The PaymentIntent hosted page has no server-side URL: it needs Airwallex.js redirectToCheckout() in the browser and redirects to successUrl (return_url only as fallback); the JS-free Checkout Session needs API version 2026-05-29+ and is absent from the published OpenAPI (latest 2026-08-21). *(quickstart.md lines 117-166; ai-agent-payments-integration.md line 54; checkout-session/quickstart.md line 14; airwallex-openapi-latest.json paths)*
- FPX through Airwallex only accepts 1.01 to 2,000 MYR per transaction and needs 15-20 business days of activation; there is no generic minimum and no FPX-specific sandbox bank, only the generic simulate-shopper-action API. *(https://www.airwallex.com/docs/payments/payment-methods/apac/fpx.md lines 19, 24-25; simulate-shopper-action.md lines 18-42)*

## Rules that apply to every Malaysian gateway

1. Amounts are integer sen. Never compare floating-point ringgit.
2. Never mark an order paid from the return URL or the callback body alone: verify the signature, ask the gateway again,
   then match reference, amount and currency exactly (`confirmPayment` does all three).
3. Gateways retry callbacks: marking an order paid must be idempotent.
4. Use one reference per payment attempt, so a late callback from an old attempt cannot match a new one.
5. Errors and logs never contain keys or secrets.
